Help and curriculum connections

Build it: construct target angles. Measure it: read the protractor. Name it: identify acute, right, obtuse and straight angles (Grade 4). Missing angle: use right angles (90°) and straight lines (180°). Triangle angles: use the 180° angle sum (Grade 8 draft). You can drag anywhere inside the protractor, use the slider, keyboard arrow keys or ±1° buttons. Correct within 2° is accepted for construction. All challenges work offline after the page is loaded.
