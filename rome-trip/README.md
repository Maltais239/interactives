# Rome travel companion

Live app: https://maltais239.github.io/interactives/rome-trip/

Public landmark recognition and Italian practice: 42 photographed places across eight destinations, 80 speaking challenges across 16 situations, short history cards, maps, and browser-local notes. No personal travel itinerary, travel dates, accommodation address, or booking details are included.

Audio uses an installed Italian device voice. Landmark cards include photographer credits and source links.

Menu practice uses published offerings from Il Gianfornaio (Prati), L’Archetto, La Zanzara, and Gelateria dei Gracchi. Each has five reply challenges, an order selector, a practice dialogue, menu items with English explanations, and official menu and map links. Menu items were checked 9 October 2026; availability can change. Menu practice text is included in the offline cache.
