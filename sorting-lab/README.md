# Sorting Lab

Shared controls and styling for Animal Diets and Natural Resources: Resource Depot.

Edit each activity’s `game-data.json` to change cards and challenges. Edit `page-data.json` to change headings and teacher notes. Keep images as individual files inside each activity’s `assets/` directory. Animal photo attribution is recorded in `animaldiets/photo-credits.json` and linked in its teacher notes.

Rebuild both pages from the repository root:

```sh
python sorting-lab/build.py
```

The build updates cache versions for the shared script and stylesheet. Do not paste image data into the HTML or JSON.
