# Spanish Practice

[Open the app](https://maltais239.github.io/interactives/spanishpractice/).

The original 3 Minute Spanish practice app, refreshed with Dímelo’s cream,
terracotta and ink-blue journal style. Vocabulary practice, listening, verb
drills, phrase recall, sentence building and translation challenges remain.

Coffee Break Spanish now covers Darren’s supplied notes for episodes 1–9 and
the episode 10 Christmas edition. The in-app **Vocabulary check** maps all
102 note entries to their practice forms, with spelling and meaning notes.
Whole phrases and useful component words are available. Episode 9 also
reuses the existing episode 1–8 word records for review.

Corrections include *fenomenal*, *no*, *diez*, *oficina*, *fotografía*,
*ingeniero*, *Hasta otra*, and *una tienda*. Both *tu* and *tú* are separate.
The ambiguous “No me llamo Mark” retains its literal meaning; the version
with a comma is also included with an explanation.

Original vocabulary and phrase indexes are retained. Saved progress continues
under the same browser storage key, `tmSpanish_v2`, at the same app URL.
Progress remains on the browser and device where it was recorded.

The app is static, with no build step or third-party package dependencies.
Serve this directory over HTTP to run it. Browser speech synthesis provides
audio; availability and voice quality depend on the device’s installed voices.

Run the content and progress-migration checks with `npm test` in this directory.
The root repository’s `RESPONSIVE-DESIGN.md` governs rendered screen checks.
