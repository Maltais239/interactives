# Sound, Structure, Spell

A free student workbook adapted from Dr. Shelley Blackwell, SLP.D’s 2025 *Sound, Structure, Spell*. It opens directly to one activity. Contents lets students jump to any of the 11 topics, 29 days or lesson word banks.

Day 1 of vowel–consonant–e uses the printed discovery and sorting groups. Its five dictated words follow the supplied teacher example. The remaining days follow the student book’s activity order. Reusable blank pages have practice words, and a few ambiguous printed examples have clearer alternatives. Open-ended analogies offer a possible match. Students’ observations and original writing remain editable.

Work saves in the current browser profile. The Contents menu can restart one day. Activity links are shareable and contain only the topic, day and activity. Student answers stay on the device.

## Run

Serve this directory as static files, or run `npm run dev`. Use `npm test` for the content and audio checks. The app needs no build step, accounts or external font or speech service. Where an English speech voice is available, the browser can use it. Otherwise it plays the bundled Flite pronunciation clips from the relevant lesson’s audio file.
