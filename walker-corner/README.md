# Mr. Walker’s Corner

Original activity ideas and recovered HTML: Tyler Walker. Classroom edition rebuilds: Engaging Students / Darren Maltais, October 2026.

| Edition | Original Google Site | Recovered original HTML |
| --- | --- | --- |

The original HTML was recovered from each public Google Site’s `data-code` embed attribute. Each source is retained unchanged. Other inspected Sites requiring sign-in were not used. These editions have separate URLs and do not change Tyler’s Sites.

The three rebuilt apps use native HTML/CSS/JavaScript and local shared assets. Function rules are parsed as arithmetic expressions, never evaluated as JavaScript. The bridge app uses an explicitly labelled relative-unit classroom model; it is not a structural engineering simulator. Plural Practice retains Tyler’s original 60-word bank, with eight added contrast words and a special explanation for `quiz → quizzes`.

Snapshots shown on the Corner and catalogue are screenshots of the running apps. Refresh `learning-lab-images/walker-{functions,bridge,plurals}.jpg` when the design changes.
