How this model works

A simplified formula assigns each bridge type a base capacity. Material, bracing and end supports adjust it; a centre pier halves the unsupported span. Wind and model self-weight reduce capacity. Costs use classroom credits.

The model demonstrates relationships. It does not calculate real bridge safety, actual tonnes, or construction costs.
