Different. Shared. Connected.

  1. Name your circles. Pick two or three things to compare, and choose their colours.
  2. Add ideas. Type one note per line, then drag notes from the bank into your diagram.
  3. Place without dragging. Select a note, then choose a region below the diagram. Keyboard users can Tab to a note and press Enter or Space.
  4. Keep creating. Double-click to edit. Use Undo, Lists, or the expanded workspace whenever you need them.
  5. Make a sorting activity. Turn on the answer key, select notes to choose their correct regions, or sort them yourself and use the current placements as the key. Return them to the bank, then save the file for students.
  6. Save and share. Your work saves automatically in this browser. Download a diagram file to open on another device, or export an image / print a PDF.

On a keyboard: arrow keys nudge a focused note; Shift + arrow moves farther. Delete removes it. Ctrl/Cmd + Z undoes. Escape deselects. Dragging uses the centre of the note to choose its region.
