Sorting Game Builder

Build a custom card sort, add your own images, and share a game that works with touch and keyboard controls.

Use 2–8 categories and up to 80 cards. Text works on its own; you can add your own images after building the list.

2 · Review the cards

The downloaded HTML includes the game and any uploaded images. Open it locally, or host it on GitHub Pages. Review the categories before sharing.
