Teacher Morpheme Maker

Create a word-family game from editable clues, then preview and share it with your students.

1 · Choose word families

Known bases load editable starter clues. A new base starts with a blank clue for you to complete.

How to use the game

Review each word’s parts, completed spelling and meaning. Add a spelling note whenever joining the parts changes the spelling. The downloaded HTML includes the whole game and can be opened locally or hosted on GitHub Pages.

2 · Review and edit

Each row is one accepted construction. Leave a prefix or suffix blank when the word has none.
